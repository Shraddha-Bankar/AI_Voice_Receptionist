# Abstract

AI Voice Receptionist is an AI-powered virtual receptionist designed for healthcare environments. The system enables users to interact through voice in English, Hindi, and Marathi. Using Speech Recognition, Natural Language Processing (NLP), and Large Language Models (LLMs), it understands user queries and provides intelligent voice responses. The project aims to reduce receptionist workload, improve patient accessibility, and provide faster communication.

---

# Introduction

Hospitals receive numerous patient inquiries daily regarding appointments, doctors, timings, and services. Managing these requests manually can be time-consuming. AI Voice Receptionist automates these interactions using conversational AI, making healthcare communication more efficient and accessible.

---

# Literature Review

Recent advancements in Speech Recognition, NLP, and AI-powered chatbots have improved human-computer interaction. Voice assistants are increasingly being used in healthcare to enhance accessibility and reduce administrative workload.

---

# Methodology

The user speaks through a microphone, and the system converts speech into text using the Web Speech API. The text is analyzed using an AI model through OpenRouter. After understanding the user's intent, the system generates an appropriate response and converts it back into speech using Text-to-Speech technology.
